# Data availability

The images, masks and annotations are **clinical data and are not distributed in this repository**
(no clinical photographs, patient information, annotation files, or feedback data are tracked; see
`.gitignore`). Access to the data is at the discretion of the authors.

What is provided instead:

| File | Content |
|---|---|
| `folds.csv` | The exact stratified 5-fold assignment of the U-Net development images, one row per image (file name, class, validation fold). File names are code + running number only (e.g. `normal/images/BT1.jpg`, `lichen/images/lc12.jpg`). Re-create it with `python ml/split_unet_folds.py`. |
| `../configs/final_config.yaml` | All inference parameters of the released model. |
| `../results/` | Metrics, per-image predictions and confusion matrices on the 89-image independent test set, generated by `ml/evaluate.py`. |

## Dataset composition

| Set | Images | Details |
|---|---|---|
| YOLOv8s-seg train / val | 598 / 185 (783) | 1 class ("lesion"); all lesion images + 20 % background images in train (`ml/train_yolo.py`) |
| U-Net development (5-fold CV) | 941 | normal, OLP and other lesions; stratified 5-fold, ~775 train / ~194 validation per fold |
| Independent test set | 89 | 30 normal, 29 OLP, 30 other lesions; never used for training or model selection |

Splits are by **image**, not by patient (patient identifiers are not available in the dataset), so
a patient with several photographs may appear on both sides of a split.
